Kuindzhi · engineering note

From a sentence to pixels

Models in Kuindzhi produce exactly two kinds of input: where to edit (a mask of weights per pixel) and what to do (a small JSON plan picked from a fixed menu). Every output pixel is then computed by our own SkSL shaders from the original photo. The language model never sees the photo, and nothing it can output describes pixels.

Model output: a selection or a plan Our code: deterministic, writes the pixels Crosses the network (optional cloud tier)

The whole pipeline

Two paths run on the phone and meet in the render engine. The photo path is computed once per photo; the command path runs per request. Only the render engine writes pixels, and it always starts from the original.

What each stage actually produces

Real outputs for the bundled portrait (CC0). Model images come from the same .tflite files with the app's preprocessing; the edited results were rendered by the app in the iOS simulator and pulled from its cache.

One step is one shader pass

Each enabled step in the stack becomes one full-frame draw with ADJUST_SKSL. The step's adjustment picks a branch in the shader by its index in the catalog; the mask decides how much of the result each pixel gets.

The exposure branch, as shipped (src/engine/shaders.ts)

if (o == 0) {
  // exposure: linear-light gain, soft shoulder so highlights don't clip
  float3 lin = toLin(c) * exp2(a * 2.0);
  if (a > 0.0) {
    float knee = 0.8;
    float3 over = max(lin - knee, 0.0);
    float3 soft = min(lin, float3(knee))
                + (1.0 - knee) * (1.0 - exp(-over / (1.0 - knee)));
    lin = mix(min(lin, float3(1.0)), soft, smoothstep(0.0, 0.25, a));
  }
  r = toGam(lin);
}
// … 21 more branches …
float3 outc = mix(c, r, m);   // m = the region mask

What the language model is allowed to say

The plan is the only thing an LLM contributes. Its output is constrained to this schema (structured outputs on Claude, guided generation on Apple's model), then clamped and filtered by normalizePlan(). There is no field that could carry an image.
